# Svetainė

Darbo sritis **Svetainė** skirta viešos svetainės vusa.lt turiniui: puslapiams, naujienoms,
kalendoriui, meniu, baneriams ir failams. Kiekvienas padalinys tvarko savo svetainės dalį
(pvz., `mif.vusa.lt`), o bendrą turinį – VU SA CB.

## Kas mato šią sritį

Kiekviena skiltis rodoma tik turintiems teisę matyti tos rūšies įrašus. Apžvalga rodoma turintiems
teisę matyti puslapius.

| Skiltis | Adresas |
|---|---|
| Apžvalga | `/mano/dashboard/svetaine` |
| Puslapiai | `/mano/pages` |
| Naujienos | `/mano/news` |
| Kalendorius | `/mano/calendar` |
| Baneriai | `/mano/banners` |
| Navigacija | `/mano/navigation` |
| Greitosios nuorodos | `/mano/quickLinks` |
| Renginių tipai | `/mano/eventTypes` |
| Žymos | `/mano/tags` |
| Failai | `/mano/files` (reikia `files.read.padalinys`) |
| Dokumentai | `/mano/documents` (reikia `documents.read.padalinys`) |
| Studijų rinkiniai | `/mano/studySets` |

Mygtukas **+ Sukurti** šioje srityje siūlo **Nauja naujiena**.

Dokumentų skiltis aprašyta ViSAK skyriuje: [Dokumentai](/visak/dokumentai).
