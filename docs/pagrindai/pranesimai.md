# Pranešimai

Platforma praneša apie tai, kas reikalauja tavo dėmesio. Pranešimai matomi platformoje (varpelis
viršutinėje juostoje), gali būti siunčiami el. paštu (iškart arba suvestine) ir į telefoną, jei
įjungei „push“ pranešimus.

::: warning Rašoma
Šis puslapis dar rašomas. Kai bus baigtas, jame bus skyriai **Kaip tai veikia**, **Veiksmai**,
**Kas ką gali** ir **Pranešimai ir automatika**, kaip [Rezervacijų](/rezervacijos/rezervacijos) skyriuje.
:::
