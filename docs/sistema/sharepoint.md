# Sharepoint failai

Institucijų dokumentai, laikomi Sharepoint. Tai failai, pridedami prie įrašų, pavyzdžiui, posėdžių.
Priklausomai nuo dokumento tipo ir įrašo, dokumentas gali būti viešas arba privatus.

Skiltis pasiekiama adresu `/mano/sharepointFiles`.

::: warning Rašoma
Šis puslapis dar rašomas. Kai bus baigtas, jame bus skyriai **Kaip tai veikia**, **Veiksmai**,
**Kas ką gali** ir **Pranešimai ir automatika**, kaip [Rezervacijų](/rezervacijos/rezervacijos) skyriuje.
:::
