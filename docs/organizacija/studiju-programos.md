# Studijų programos

VU studijų programų sąrašas. Studijų programos priskiriamos pareigybėms tiesiogiai, todėl
svetainėje galima rodyti, pavyzdžiui, kiekvienos programos studentų atstovus.

Skiltis pasiekiama adresu `/mano/studyPrograms`.

::: warning Rašoma
Šis puslapis dar rašomas. Kai bus baigtas, jame bus skyriai **Kaip tai veikia**, **Veiksmai**,
**Kas ką gali** ir **Pranešimai ir automatika**, kaip [Rezervacijų](/rezervacijos/rezervacijos) skyriuje.
:::
