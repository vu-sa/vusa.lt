# Platform updates: v2

This page covers v2 changes that already run on vusa.lt. The new version of My VU SR is
summarized in [v3.0](/en/changelog/v3#v3-0). Guide links open Lithuanian instructions.

## v2.2 — Editing unit homepages (2026-09-14) {#v2-2}

- ✨ **Undo a reservation action** — step back from an incorrect approval, handover, or return; the reason remains in the history. [Guide](/rezervacijos/rezervacijos#veiksmai)
- 🔧 **More reliable unit content and contacts** — homepage editing opens the correct unit, and contacts update when a member, duty, or assignment period changes. [Units](/organizacija/padaliniai), [duties](/organizacija/pareigybes)
- 🔧 **Correct PKP institution links** — on contact category pages, institution cards open the contacts page on www.vusa.lt instead of a non-existent PKP subdomain.
- ✨ **Topics and event types** — topics group related content, events can have a separate type, and old category links redirect to topics. [Tags and topics](/svetaine/zymos#temos-puslapis), [event types](/svetaine/renginiu-tipai)

## v2.1 — Bilingual homepage (2026-09-07) {#v2-1}

- ⭐ **A homepage in both languages** — edit Lithuanian and English versions independently; Lithuanian remains the fallback until English is ready. [Guide](/organizacija/padaliniai)
- ✨ **Clearer website content** — institution pages include working hours and social account handles; text and process-step editors support links. [Institutions](/visak/institucijos), [content editing](/svetaine/puslapiai#turinio-redagavimas)
- 🔧 **More precise unit permissions** — an organization-wide permission no longer broadens unrelated permissions limited to one unit. [Guide](/pagrindai/teises#kaip-sistema-nusprendzia)

## v2.0 — Public site redesign and visual content editor (2026-09-05) {#v2-0}

- ⭐ **A refreshed public website** — a new design, two-level navigation, managed footer menus, and updated event, contact, and study-set pages. [Navigation](/svetaine/navigacija), [calendar](/svetaine/kalendorius)
- ⭐ **Visual content editing** — edit text and content blocks in the page preview, including full-screen mode. [Guide](/svetaine/puslapiai#turinio-redagavimas)
- ⭐ **Accessibility controls** — adjust text size, contrast, and link underlining on the public website.
